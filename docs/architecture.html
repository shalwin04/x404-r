🔄 Crash Recovery Flow

1

Normal Execution

Worker executes task, calling checkpoint() to save progress atomically to CockroachDB.

await ctx.checkpoint({ progress: 3 });
2

Crash Happens

Worker crashes (Lambda timeout, OOM, network error). Last checkpoint is preserved in DB.

💥 Worker died at step 3
✅ CockroachDB has state: {p: 3}
3

Automatic Recovery

New worker claims task, loads checkpoint, resumes from last saved state. Zero progress lost.

let p = ctx.state.progress || 0;
// p = 3, continue from here!
