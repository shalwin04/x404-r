Why CockroachDB? 3 Critical Features

🔒 FOR UPDATE SKIP LOCKED

SELECT * FROM tasks WHERE status = 'pending' FOR UPDATE SKIP LOCKED LIMIT 1;

Atomic task claiming. No race conditions. Multiple workers compete fairly.

🔄 Distributed Transactions

BEGIN; UPDATE tasks SET state=$1; INSERT INTO checkpoints...; COMMIT;

Checkpoint + state saved atomically. No partial corruption.

📊 JSON + Vectors

state JSONB, embedding VECTOR(1536)

Flexible state storage. Memory vectors for agent learning.
